# Bagan Museum V2.1
Native Kotlin/Jetpack Compose Android app, branched from V2.0.
- Public Wikimedia Commons searched image thumbnails for monument cards, with source-file and license links. Offline fallbacks remain native concept art. Search matches are not manually verified.
- Native English/Myanmar monument-specific Android text-to-speech with play/stop, next/previous and rate control; phone voice pack required.
- GLB Viewer: three clickable projected hotspots that follow camera rotation. Anchors approximate teaching positions; not archaeologically measured geometry.
- Preserves Maps search, content, Drive source directory, 10 offline concept GLBs, AR proof-of-concept, quiz, favorites.
- Original Drive Blender files still have not been exported into the APK.
- Real device runtime and Commons thumbnail correctness need physical QA.
