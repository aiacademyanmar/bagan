# Bagan Museum Native V2.0
Version 2.0.0 • New branch: `bagan-museum-native-v2-0`. Previous app versions remain unchanged.

## New features
- Expanded ten-monument bilingual Myanmar/English offline content library (architecture, heritage, location context and teaching highlights)
- Native info topics for each offline GLB viewer (three selectable conceptual information hotspots per monument)
- Map directory using Google Maps **place-name search** through ACTION_VIEW. No Maps API key and no exact coordinates are claimed. No turn-by-turn directions are generated by the app.
- Virtual entry-gateway concept explicitly has **no physical place pin**
- Public photo discovery in Wikimedia Commons MediaSearch (links open externally so source attribution and usage licenses remain visible).
- Home and Monument Detail routes to map/photos. Retains 10 original concept GLB assets, ARCore museum proof-of-concept, QR links, quizzes, audio and native UI.
- Original offline monument art is illustrative native Compose drawing, **not** a photograph or measured monument scan.

## Important limitations
Wikimedia public photographs are browsed *online* and are **not packaged inside the APK**; the app does not claim to redistribute pictures without attribution.
Location searches are returned by Google Maps and should be verified by the visitor; the app does not provide surveyed coordinates, live maps in-app or route/ETA metrics.
The ten separately generated GLBs remain concept geometry, **not original Blender export from the user Drive**. The original project is still privately stored in Google Drive.
ARCore on a real phone and Android TTS voice compatibility still require runtime QA.

## Build
GitHub Actions in branch `bagan-museum-native-v2-0`. APK debug for Android 8.0+; 10 offline GLBs are validated during build.
