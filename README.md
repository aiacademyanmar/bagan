# Bagan Museum Native V2.2
- Monument-specific AR selection of one of ten included original concept GLBs; requires Google Play Services for AR and a compatible camera device
- Disk cache of Commons image thumbnails (up to ten) and attribution metadata, available offline after initial fetch; clear cache in Photo Gallery
- Existing 3D click hotspots with photo-link information
- Android TTS chapter completion saved only when playback finishes; stored locally
- Native 21-screen UI retained, including offline quizzes, map search, and links to Drive Blender source projects
- Not an official museum, archaeological scan or historic reconstruction; original Drive Blender models not yet exported to GLB
- Compile is not equivalent to device QA: ARCore camera, Commons API, and TTS require phone testing
