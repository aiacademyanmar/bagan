# BAGAN Native V3.4.3
Native Kotlin Compose Android application using SceneView 4.37.0 (Filament) for 3D GLB.
All 13 model URLs point to https://aaii.asia/bagan/3d/models/.
Models must first be uploaded to that cPanel directory with exactly matching names.
No WebView and no Google Drive API key. Android SDK/Gradle compilation is required.
GitHub Actions workflow emits debug APK when build succeeds.
